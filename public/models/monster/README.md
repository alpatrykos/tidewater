# Monster Energy can texture

`label.png` is a flat can wrap generated with the built-in imagegen tool on 2026-09-25 at the user's request. It recreates the classic black and neon-green Monster Energy packaging. This is a generated recreation, not an official print-ready label file.

The full image wraps around the can, with the front artwork centered at U = 0.5. The renderer supplies lacquer, condensation, and lighting; separate geometry supplies the silver lid, rims, and moving pull tab. Held and discarded cans share the same artwork.

The exact generation prompt is saved in `prompt.txt`. Monster names and packaging marks belong to their respective owners.
