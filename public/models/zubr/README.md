# Żubr classic can texture

`label.png` is a flat wrap generated with the built-in imagegen tool from the user's supplied photograph of the older Żubr can on 2026-09-24. It recreates the dark-green label, realistic bison, white band with black ŻUBR lettering, red 1768 badge and brewery shield. This is a generated reconstruction, not an official print-ready label file.

The image is used as an sRGB albedo texture. The main design is centered at U = 0.5. Physical can circumference / printed height is approximately 1.45, matching the image aspect ratio. The 3D model provides the metallic rims, lid, pull tab and lighting.

Żubr names and packaging marks belong to their respective owners. The source photograph was supplied directly in the task; no third-party packshot was downloaded. The generation prompt is saved in `prompt.txt`.
